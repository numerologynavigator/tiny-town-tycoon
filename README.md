# Tiny Town Tycoon: website

The public page and privacy policy for the Android game Tiny Town Tycoon, served with GitHub Pages.

- `index.html`: home page ("Coming soon to Google Play"; no store link until the app is published)
- `privacy.html`: the privacy policy, the address entered in Google Play Console
- `assets/`: the app icon and three screenshots

This repository holds only the website. It does not contain the game's source code, signing keys or
advertising ids.
